☁️ 云同步设置

1. 打开 GitHub Token 设置页
2. 点 "Generate new token (classic)"
3. 勾选 gist 权限，生成token
4. 把token粘贴到这里
第一次保存设置时会自动创建一个Gist用于存储你的做题数据
📖 使用说明：
1. 在电脑上配置好Token后，数据会自动同步到你的GitHub Gist
2. 在手机上打开同一个网页，填入同一个Token，就能同步到电脑上的数据
3. Token只存在你自己的浏览器里，不会上传到任何服务器
4. 每次做题后会自动同步，也可以点"立即同步"手动同步
